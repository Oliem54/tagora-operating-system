# Paquet de transfert — Identité / bootstrap : TAGORA Nexus

```text
TOS_SCOPE_ONLY=YES
PRODUCT_APPLICATION_BY_TOS=NO
MARTIN_TRANSFER_REQUIRED=YES
SOURCE_ADR=ADR-0009
SOURCE_DECISION=DEC-021
SOURCE_VALIDATION=VALD-100
ENTRA_AUTHORIZED=NO
SSO_AUTHORIZED=NO
DB_AUTHORIZED=NO
IMPLEMENTATION_AUTHORIZED=NO
```

Martin transfère ce paquet à l'agent TAGORA Nexus. TOS n'implémente rien.

Aucun Entra, app registration, OAuth, secret, DB, utilisateur réel, SSO.
